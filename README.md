# Tesitura

App personal para profesores de canto: alumnos, repertorio con transposición, calendario con clases recurrentes, registro pedagógico, horas, ingresos por escuela y facturas en PDF.

Hecha por Facundo Burgos · [@facuuuburgos](https://instagram.com/facuuuburgos)

- Funciona como app instalable en el iPhone (Safari → Compartir → Agregar a inicio) y sin conexión.
- Los datos se guardan en el dispositivo y, con una cuenta, se sincronizan en Supabase (tabla `tesitura_data`, ver `supabase.sql`).
